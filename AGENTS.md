# Personal profile repository

This is a personal GitHub profile, not a company operating control plane.
Keep changes focused on the requested profile content and existing assets.

- Preserve the owner's voice and verify factual claims against owner-provided
  evidence; using a tool is not proof the owner authored it.
- Preview Markdown and verify changed local links and `git diff --check`.
  There is no application build to invent for profile-only edits.
- Local edits and review preparation within the task may proceed. Publication
  or external messages must be covered by the user's request.
- Do not import private company, career, customer, or credential data into this
  public-facing repository. Do not apply company portfolio priorities here.
